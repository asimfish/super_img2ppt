# Main-figure test artwork

UniAD: Planning-oriented Autonomous Driving, CVPR 2023, Figure 2. Source repository
OpenDriveLab/UniAD, commit `532fc330151758c5e345aef74d2a1bf1042e50ab`,
`sources/pipeline.png`. Its pinned README explicitly places all assets and code under
Apache 2.0 unless otherwise specified. Complete license: [UNIAD_APACHE_2.txt](licenses/UNIAD_APACHE_2.txt).
Attribution: UniAD authors and OpenDriveLab; this reconstruction does not imply endorsement.
Source was visually checked against the official paper figure. Changes: native text, shapes,
connectors and eight local image crops; fonts and approximate geometry differ. TrackFormer
and MapFormer retain noneditable labels fused with artwork. No fonts are distributed.

The Grounding DINO ECCV2024 and GLaMM CVPR2024 tests use raster crops of their published PDFs,
which differ from their author-repository image variants. Their original/derived artwork stays
in local test output because the repository licenses were not assumed to license those PDFs.
Source URLs, hashes, crop recipes, local artifact identities and engineering evidence are
retained in `docs/evidence/main_figures`; the repository fetcher reproduces the tested images.
