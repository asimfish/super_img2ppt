# Scope and acceptance before new runtime changes

Add three complete 2026 world-model/embodied method figures from licensed official PDFs:
DreamZero Fig4, Cosmos Policy Fig2, Cosmos3 Fig5. Every panel/readable label retained, native
objects where representable, explicit raster/unsupported boundaries. Inspect actual PPTX and
source-width comparisons; preserve failed attempts and no aggregate fidelity claim.

Known evaluation weakness from prior OpenVLA report: a manually chosen text ROI included a
circle, and another historical ROI clipped a glyph. A bounding-box/IoU number alone did not
establish a valid complete-text comparison. Repeated case scripts currently reimplement
mask selection and do not consistently expose boundary contact or empty source masks.

Candidate reusable improvement: explicit ROI comparison of same-size source and actual images,
no registration/resizing or success threshold, color-mask counts/IoU/bounds plus validity flags.
Boundary contact invalidates complete-ink edge metrics; source empty is not perfect match;
actual empty reports missing ink; equal extrema do not imply equal shapes. Negative/positive
synthetic oracles can verify these statements, then independently apply to actual new cases.

Do not expand arbitrary-angle support merely by widening schema: rendered-text orientation,
ownership, clipping and width checks must remain meaningful. Treat any new limitation exposed
by the independent cases as separate evidence before considering such changes.
